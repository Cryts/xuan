# 修仙游戏「体系包 / 奇遇事件库」设定研究：以 24 部网文构建可切换世界

## 摘要：A级体系包已形成四类玩法骨架，首发应覆盖凡人流、天才流、凡人成神与诡秘失控四条主线

本研究按“可核验性 + 体系完整度 + 玩法适配度”筛选 24 部作品，覆盖凡人流、天才流、苟道流、高武流、东方克苏鲁流与升级爽文。被用户列为候选的《飞升大荒》未找到可核验的对应小说，因此不收录；《深空彼岸》作品真实，但公开权威资料不足以完整复原境界序列，仅作为 C级可选包保留，并明确标注“完整境界待核实”。

24 部作品中，《凡人修仙传》《斗破苍穹》《完美世界》《仙逆》《诡秘之主》《大奉打更人》《道诡异仙》《吞噬星空》《我师兄实在太稳健了》等最适合作为首发体系包。它们的共同点不是境界数量多，而是升级资源、外挂、风险与身份选择能够转化为明确数值：凡人流强调资源节流和长线回报，天才流强调资源堆叠与连击爽感，诡秘流强调序列、扮演与失控博弈，高武/星空流则便于将战力外推至宇宙尺度。

建议游戏不直接复制任何单一作品，而应将所有体系映射到统一的“力量层级 Index + 战力区间 + 资源槽 + 污染/心魔槽”。切换体系时，可以替换术语、奇遇偏好和失败惩罚，但保留角色资产迁移能力。奇遇库则应围绕“得到什么、暴露什么、需要偿还什么”设计，而非把秘境、夺宝、退婚等母题重复做成随机奖励。

## 1. 研究边界决定“体系包”不能等同于“照抄原著”

本报告服务于文字修仙游戏的 World Pack 与奇遇事件库，因此将作品拆为四类承重资产：**主境界序列**、**资源与核心词**、**主角外挂**、**标志性事件**。由于许多小说仍处于连载中，或不同篇章采用不同分阶口径，以下等级均按“作品世界主线采用的、可连续升级的主序列”计数。

凡人流通常以“普通资质 + 稳定外挂 + 谨慎决策”为骨架；天才流强调少年受挫、名师、异火/骨文和跨地图连续升级；诡秘流则把序列、魔药、扮演、失控、阵营及外神压力转化为生存机制。由此可见，体系包的核心并非术语数量，而是能否形成“投入—升级—风险—身份变化”的完整循环。

来源层级依次为作家协会/出版社、平台与作者公开资料、原著目录或正版百科，再辅以文学评论。网络百科和部分二次资料对后期“亚境界”或“终局境界”存在分歧时，本表优先保留原著明确的主干，并标注“待核实”，不以推测补全。奇遇事件则依据已核验的核心情节进行游戏化扩写：保留母题和关键收益，但不把二次创作细节写成原著事实。

作品筛选结果显示，用户列出的 25 个名称中，24 部可以核验，1 部不应收录。

|核验结论|作品或处理|
|---|---|
|已核验，纳入正文|凡人修仙传、斗破苍穹、武动乾坤、大主宰、完美世界、遮天、莽荒纪、雪中悍刀行、将夜、择日飞升、赤心巡天、大奉打更人、诡秘之主、宿命之环、道诡异仙、诛仙、仙逆、一念永恒、飞剑问道、星辰变、吞噬星空、我师兄实在太稳健了、深空彼岸|
|未找到可核验对应作品，剔除|《飞升大荒》|

这意味着，即使剔除一部作品，候选池仍超过用户要求的 12 部，足以支持多套首发体系和差异化玩法。

## 2. 长成长序列更适合做首发体系，短序列则适合压缩成独立赛季

A级推荐的标准不是作品人气排名，而是体系能否直接支撑数值层、资源层、奇遇层与长期切换。《凡人修仙传》《斗破苍穹》《完美世界》《仙逆》《诡秘之主》可作为四个首发支柱：前者覆盖慢热经营，次者覆盖爽快成长，三者覆盖肉身与纪元式升级，后者覆盖信息解谜和非凡失控。

《大奉打更人》是东方化多路径体系的成熟范本，《大主宰》《星辰变》《吞噬星空》适合宇宙/位面扩张。《我师兄实在太稳健了》能够单独支撑苟道生存线；《宿命之环》《道诡异仙》则可作为诡秘玩法的变体包。它们的共同优势是：等级变化不只是战力数字变化，还会改变行动成本、信息权限、阵营关系和失败后果。

B级作品并非设定不足，而是更适合资料片、事件主题或限定赛季。《雪中悍刀行》《将夜》《飞剑问道》的境界数量较少，叙事和人物权重高于机械升级；《赤心巡天》规模宏大，但公开口径难以稳定压缩为基础游戏包；《诛仙》的经典性足以支撑情怀内容。C级《深空彼岸》只建议作为“旧术/新术 + 星际规则融合”的实验包，完整境界需待原著资料补足后再定级。

## 3. 24 部作品的体系、外挂与奇遇均可压缩为统一事件结构

以下逐书结构采用固定字段：主境界、资源/核心词、主角外挂、玩法气质与 8—12 条奇遇事件。事件均按“情境 → 触发 → 选项 → 结果/风险”表达，收益不限于数值，还包括身份暴露、理智污染、阵营仇恨和后续债务。

事件设计的关键不是增加选项数量，而是让每个选项改变不同的长期变量。例如，“直接服用”可能提高突破速度但增加污染；“上交组织”会降低收益，却可能获得庇护和后续任务；“伪装身份”则同时承担欺诈失败与阵营牵连风险。

### 3.1 《凡人修仙传》：慢热经营的核心是“以时间换取可控突破”

**作品信息**：忘语，起点中文网，2007—2013；凡人流、仙侠修真。[1]

**完整境界序列**：炼气 → 筑基 → 结丹 → 元婴 → 化神 → 炼虚 → 合体 → 大乘 → 渡劫 → 飞升；人界篇章通常止于化神，灵界续接炼虚—合体—大乘—渡劫，仙界还有真仙等更高层次。下文主序列按 12 级口径，即炼气、筑基、结丹、元婴、化神、炼虚、合体、大乘、渡劫、真仙、金仙、大罗，后续仙界细分可另设亚层。

**资源与核心词**：灵气、灵石、丹药、灵药、符箓、法宝、灵根、掌天瓶、夺舍、空间节点。

**主角金手指**：掌天瓶可催熟灵药；韩立以伪灵根、谨慎性格、多次化形/分身和提前准备后手补足资质劣势。

**玩法气质**：养成慢热、稳健经营。

**标志性奇遇事件**

1. **山洞捡到神秘小瓶**：早期探索废弃洞府时触发。  
   - 触碰瓶中残液 / 带走瓶子 / 上报师门。  
   - 获得灵药催熟能力；过早暴露可能引来夺宝。

2. **墨大夫的夺舍暗算**：师父传功期间触发。  
   - 服下控制药物 / 反制夺舍 / 逃出洞府。  
   - 胜则获得遗产与教训，败则失去肉身或资质。

3. **太南小会得知仙路**：抵达修仙坊市时触发。  
   - 低调购材 / 主动攀谈 / 高价竞拍。  
   - 可获取修炼资源，也可能暴露身份或负债。

4. **升仙大会测出伪灵根**：参加宗门选拔时触发。  
   - 咬牙苦修 / 用资源弥补 / 转投旁门。  
   - 决定前期成长斜率与剧情阵营。

5. **筑基丹原料的长期培育**：获得稀有灵药种子后触发。  
   - 马上出售 / 用掌天瓶催熟 / 与人合作种植。  
   - 长线养成可获得突破资源，期间可能被劫。

6. **野狼帮灭门夜的反杀**：宗门遭袭时触发。  
   - 硬战 / 埋伏 / 伪装伤亡撤退。  
   - 首场高风险战斗；过度逞强可能死亡。

7. **修士尸身的遗产争夺**：秘境或追杀途中触发。  
   - 搜刮战利品 / 留下痕迹掩盖 / 通知宗门。  
   - 收益与仇杀风险同步上升。

8. **墨彩环线报与解药**：被下毒后触发。  
   - 追踪来源 / 交换情报 / 杀人灭口。  
   - 决定后续人脉和心性倾向。

9. **古传送阵与空间节点**：中高阶地图切换时触发。  
   - 立即穿越 / 先布退路 / 探查阵法。  
   - 成功则开新地图，失败可能迷失。

10. **妖兽反噬的驯养尝试**：获得妖兽卵或幼兽时触发。  
    - 契约 / 放生 / 强炼妖丹。  
    - 驯服后可作战，强炼可能遭反噬。

11. **元婴前备下第二元婴**：突破关键期触发。  
    - 冒险分神 / 延期稳固根基 / 夺他人元婴。  
    - 获得保命分身，但会引发因果和仇敌。

12. **飞升仙界的资源断档**：抵达新位面时触发。  
    - 低调做散修 / 依附势力 / 掠夺土著。  
    - 决定新地图生存方式和阵营仇恨。

凡人流的可玩性来自“慢”，因此游戏必须将掌天瓶、灵药培育和时间跳跃设计为核心循环，而不能把韩立改造成典型天才。若跳过经营阶段，凡人流就会失去与天才流之间的差异。

### 3.2 《斗破苍穹》：异火、炼药与仇恨共同构成成长发动机

**作品信息**：天蚕土豆，起点中文网，2009—2011；天才流、玄幻热血。[2]

**完整境界序列**：斗之气（1—9段）→ 斗者 → 斗师 → 大斗师 → 斗灵 → 斗王 → 斗皇 → 斗宗 → 斗尊 → 半圣 → 斗圣 → 斗帝。

**资源与核心词**：斗气、丹药、异火、炼药师、魔核、纳戒、骨灵冷火、焚诀、魂殿。

**主角金手指**：戒指中的药老残魂传授功法、斗技与炼药；萧炎另有焚诀和多种异火。

**玩法气质**：快意恩仇、爽文养成。

**标志性奇遇事件**

1. **被退婚的三年之约**：少年期剧情触发。  
   - 当场立约 / 隐忍退场 / 挑衅对方长辈。  
   - 建立长期复仇目标；过早冲突可能伤亡。

2. **戒指幽魂苏醒**：家族受辱后触发。  
   - 接受师徒契约 / 拒绝交易 / 先求自保。  
   - 获得修炼导师，但需承担偿债条件。

3. **魔兽山脉偶遇小医仙**：外出历练时触发。  
   - 结伴 / 保持距离 / 利用地形救人。  
   - 获得厄难毒体相关支线与人脉。

4. **拍卖会捡漏残卷**：城市坊市触发。  
   - 竞价 / 暗中验货 / 以物易物。  
   - 可能得到功法或异火线索。

5. **炼化第一缕异火**：获得青莲地心火等线索后触发。  
   - 直接炼化 / 借助药老 / 转售材料。  
   - 大幅提升战力，失败则可能焚身。

6. **迦南学院创建磐门**：学院大比前触发。  
   - 组建势力 / 独行修炼 / 依附强派。  
   - 开启势力经营和团队任务。

7. **塔中修炼与陨落心炎**：学院禁地触发。  
   - 压制心炎 / 借火炼体 / 联合镇压。  
   - 获得火能，也有失控和伤亡风险。

8. **丹会夺冠**：成为高阶炼药师后触发。  
   - 激进成丹 / 稳中求胜 / 合作控场。  
   - 决定炼药声望和顶级资源。

9. **救药老出魂殿**：获得魂殿情报后触发。  
   - 强攻 / 谍战营救 / 延迟重塑肉身。  
   - 决定导师复活线与阵营战争时点。

10. **收服三千焱炎火**：进入丹域/妖火空间触发。  
    - 正面对抗 / 借天地异火规则 / 放弃火种。  
    - 高阶突破关键资源，代价极高。

11. **古帝洞府传承**：集齐古玉条件后触发。  
    - 争夺传承 / 联手抗魂族 / 观望渔利。  
    - 通向斗帝级终局。

12. **双帝之战的阵营决战**：终局阶段触发。  
    - 率领联盟 / 单刀赴会 / 拖延争取仪式。  
    - 终局势力战，失败可能导致世界线败北。

萧炎型主角的成长之所以连贯，是因为“受辱—修炼—资源—复仇—更强敌人”的节奏固定。游戏若只保留异火收集，会削弱仇恨与势力责任对决策的长期约束。

### 3.3 《武动乾坤》：双职业与地图扩张适合采用赛季式结构

   - 引更强天劫 / 压制雷数 / 借功德化解。  
   - 风险与上限交换。

4. **洪荒小国教化的功德经营**：建立势力后触发。  
   - 低调积功德 / 高调传教 / 借天道庇护。  
   - 长期稳健资源。

5. **截教/阐教阵营的边缘试探**：封神式剧情触发。  
   - 站队 / 中立 / 暗助弱者。  
   - 高因果风险。

6. **灵宝现世的抢与不抢**：秘境触发。  
   - 不抢 / 智取 / 替人保管。  
   - 苟道式资源取舍。

7. **金丹版纸道人的研究**：炼器触发。  
   - 成功量产 / 失败暴露 / 改良配方。  
   - 技术树事件。

8. **大罗证道的道境选择**：高阶突破触发。  
   - 顺应天道 / 自创大道 / 守护人间。  
   - 终局身份分支。

9. **鸿蒙紫气成圣的诱惑**：终局前触发。  
   - 成圣受缚 / 拒绝紫气 / 另寻超脱。  
   - 决定结局自由度。

苟道玩法的难点是避免无聊。解决方案不是减少谨慎收益，而是让“稳健”消耗时间、材料和信息：玩家越不冒险，越需要提前经营；一次冒进则可能毁掉多阶段布局。

### 3.23 《深空彼岸》：作品可收录，但完整境界序列必须待核实

**作品信息**：辰东，起点中文网，2021—2023；科幻修仙、旧术新术。[23]

**完整境界序列**：公开二次资料常称“人世间、逍遥游、养生主、羽化仙、幕天境、御道境”等，并提及“全领域六破”；但本研究未取得足以精确定序的一手或权威完整原文，因此完整序列**待核实**。游戏首发建议仅设 6 级占位：凡人、觉醒、旧术小成、新术融合、幕天、御道，后续必须逐章审校后替换。

**资源与核心词**：旧术、新术、内景地、规则之力、破限、元神圣物、星际文明。

**主角金手指**：旧土遗泽、多规则融合体质。

**玩法气质**：解谜探索、星际规则融合。

**标志性奇遇事件**

1. **旧土断简的失传旧术**：开局触发。  
   - 拼凑修炼 / 交给组织 / 封印研究。  
   - 决定旧术路线。

2. **内景地中的古老意识**：探索内景时触发。  
   - 接受传承 / 对抗意识 / 谈判共存。  
   - 高维意识风险。

3. **新星规则压制下的适应**：跨世界触发。  
   - 吸收新术 / 压制旧术 / 双术融合。  
   - 规则适配事件。

4. **超凡中心世界的规则吞噬**：高位地图触发。  
   - 融入中心 / 反抗吞噬 / 逃回旧土。  
   - 世界层级冲突。

5. **元神圣物的六破试炼**：高阶突破触发。  
   - 逐步破限 / 一次冲六 / 停在三破。  
   - 突破品质事件。

6. **诸天宇宙的彼岸追问**：终局触发。  
   - 抵达彼岸 / 建立新秩序 / 留在人间界。  
   - 终局哲学分支。

该作品可作为“旧术—新术—宇宙规则”的混搭实验包，但不宜在完整序列核实前进入首发。占位序列只能用于开发测试，不能包装为原著设定。

母题复用时应遵循三条约束：

1. **每个事件至少连接一个长期变量**：资源、暴露度、污染、阵营仇恨或因果。
2. **高风险不等于高奖励的唯一解**：稳健路线应更慢但更可控，激进路线更快但可能引发追杀或失控。
3. **同一母题在不同体系包中必须改变术语和风险**：例如，“秘境夺宝”在凡人流中偏向资源断档，在诡秘流中偏向封印物污染，在高武流中偏向规则压制。

## 5. 体系切换的本质是保留数值骨架、替换术语与失败方式

建议引擎不保存“斗帝”或“序列 5”等表层名称，而是保存统一的 `PowerIndex`（0—1000）。所有作品境界映射为连续段；同一段内的细分只改变资源消耗、技能解锁和剧情权限，不直接改变世界层级。

例如：

- 凡人/仙侠：0—50 为下界散修，50—200 为宗门中坚，200—400 为一方巨擘，400—600 为真仙/天仙，600—800 为金仙/大罗，800—1000 为混元/天道级。
- 斗破：斗之气—斗灵 ≈ 0—50，斗王—斗宗 ≈ 50—150，斗尊—斗圣 ≈ 150—400，斗帝 ≈ 700+。
- 诡秘：序列 9—7 ≈ 0—40，序列 6—4 ≈ 40—120，序列 3—1 ≈ 120—400，序列 0/旧日 ≈ 700+。
- 吞噬星空：学徒—行星 ≈ 0—30，恒星—宇宙 ≈ 30—90，域主—界主 ≈ 90—180，不朽—宇宙最强者 ≈ 180—1000。

上述数值只是内部设计建议，并非原著跨作品战力。不同作品的“一级”并不相等，必须通过 PowerIndex 校准。

|统一层|通用资源槽|凡人/仙侠术语|斗破/玄幻术语|诡秘术语|高武/星空术语|
|---|---|---|---|---|---|
|0—10 凡俗|体力、现金、声望|凡人、炼气|斗之气、斗者|普通人或序列 9|普通人、学徒 1—3|
|10—50 入门|灵石/丹药、基础材料|筑基、结丹|斗师—大斗师|序列 8—7|学徒高阶、行星级|
|50—120 中坚|稀有材料、势力声望|元婴、化神|斗灵—斗王|序列 6—5|恒星—宇宙级|
|120—250 高层|灵脉/法则碎片|炼虚、合体、大乘|斗皇—斗宗|序列 4—3|域主—界主|
|250—450 巨头|世界权限、阵营令牌|渡劫、真仙|斗尊—斗圣|序列 2—1|不朽—宇宙尊者|
|450—700 顶层|源质/天道权限|金仙、大罗、准圣|斗帝|序列 0、旧日|宇宙之主、最强者|
|700—1000 超脱|不可直视的真相|圣人、超脱|规则级（混搭）|外神/源质聚合|宇宙规则掌控|

资源名称也应映射为统一函数：

- `灵石 = 通用货币`
- `斗气/元力/灵力 = PowerCurrency`
- `异火 = PowerCurrency 的高纯度版本`
- `非凡特性 = 晋升材料 + 聚合仇恨`
- `基因原能 = PowerCurrency 的科技版本`
- `香火/功德 = 阵营货币或秩序稳定度`
- `污染/心魔 = Sanity 或 Corruption`

切换世界包时，旧资源可按折旧率转换，但以下资产必须保留：

- 奇遇解锁的剧情权限；
- 阵营声望；
- 因果债务；
- 封印物、污染和理智状态；
- 分身、契约与护道人关系。

这意味着，资产迁移不是无条件兑换。一个在凡人流中积累的“追杀因果”，不应因切换诡秘包而自动消失；它可以映射为聚合仇恨或外神关注。

建议为每个体系包配置独立 `TermDictionary`：

|内部键|凡人包|斗破包|诡秘包|星空包|
|---|---|---|---|---|
|LEVEL_UP|突破/结丹|进阶/炼化|晋升/消化魔药|破限/领悟法则|
|COMBAT|斗法/御剑|战斗/斗技|神秘学对抗|基因战/科技战|
|LOOT|遗府/法宝|异火/魔核|封印物/特性|遗迹/科技蓝图|
|RISK|心魔/天劫|焚身/魂殿追杀|失控/外神低语|规则反噬/种族战争|
|BOND|师徒/道侣|导师/盟友|塔罗会/教会|佣兵团/文明|

**可切换条件是规则兼容，而非名称相似。** 凡人—斗破—完美—仙逆共享“灵气/肉身/天劫/法宝”，适合默认共享基础层；诡秘包需要额外加载 `Sanity`、`Aggregation`、`SequenceLimit`，不能让普通仙侠随意炼化非凡特性；星空包则叠加 `LawComprehension`、`Domain` 和 `WorldPermission`。

混搭时可采用“主包 70% + 副包 30%”规则。例如，“凡人 × 诡秘”允许掌天瓶催熟灵药，但灵药服用会增加 `Sanity` 检定；“斗破 × 星空”允许异火映射为高能源质，却不能自动获得不朽神力。这样既能复用资产，也能避免不同体系的终局层级互相贬值。

## 6. 首发应以“凡人流、天才流、诡秘流、苟道流”四套骨架覆盖主要玩法

建议第一赛季上线 4—6 个体系包：**凡人修仙传、斗破苍穹、完美世界、诡秘之主、仙逆、我师兄实在太稳健了**。前三套负责仙侠/玄幻主流，诡秘之主负责规则解谜，仙逆补足长线赛季，稳健师兄补足低风险偏好。

《大奉打更人》《道诡异仙》《吞噬星空》《星辰变》《择日飞升》可作为第一批 DLC。它们分别提供东方诡秘、理智怪谈、高武星际、三界跃迁和志怪反天道。其余作品按主题赛季分批上线，避免将差异巨大的世界观塞入同一早期版本。

具体开发顺序如下：

1. **首发版本**：凡人、斗破、完美、诡秘、仙逆、稳健师兄。
2. **第一批 DLC**：大奉、道诡、吞噬星空、星辰变、择日飞升。
3. **第二批主题包**：雪中悍刀行、将夜、飞剑问道、赤心巡天、诛仙。
4. **实验包**：深空彼岸，仅在境界序列核实后正式定级。

最终设计原则是：**体系可以切换，角色资产必须可迁移；术语可以替换，风险结构不能消失。** 一套秘境夺宝在凡人包中应有追杀、资源断档和藏拙，在诡秘包中应有聚合、失控和身份暴露，在高武包中应有规则压制和阵营清算。只有让每个母题在不同体系包中承担不同因果，事件库才不会沦为重复抽奖。
